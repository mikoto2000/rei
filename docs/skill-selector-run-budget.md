# Skill選択用LLMのRun・Goal予算

ChatのAgentSkillAdvisorはPromptのToolContextに渡されたRunExecutionContextを使い、暗黙のSkill選択用LLM呼び出しも既存のRun呼出回数と、設定されている場合のGoal共通予算に計上する。候補の選別後、実際のモデル呼出直前に予約する。

予算不足・Run取消は通常のSkill選択失敗として握りつぶさず、既存の停止経路へ伝える。モデル呼出が失敗しても予約を戻さない。候補が空、機能無効、または既定で有効なSkillを明示指定した場合は追加予約を行わない。`rei.skills.implicit-with-explicit=true` では明示指定後の空き枠にも暗黙選択を追加する。主回答の予約は既存の実行側が担当し、Skill選択分を追加で消費する。

暗黙選択の完了待ちは既定30秒で打ち切る。設定と取消・使用量不明時の扱いは[スキル選択の待ち時間](skill-selection-latency.md)を参照。

RunContextを持たない従来の直接呼出APIは維持する。独自のAgentSkillImplicitSelection実装は追加のcallback付きAPIを使うと選択前に1回予約される。標準実装は空候補を除いた正確なモデル呼出境界で予約する。

この予算はChatモデルの呼出回数を扱う。embedding・rerankの課金量やtoken数の共通上限は対象に含まれない。
