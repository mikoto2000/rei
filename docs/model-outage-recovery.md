# Model outage recovery

### 推論サーバー障害後の待機

`rei.llm.outage-cooldown`（環境変数 `REI_LLM_OUTAGE_COOLDOWN`、既定 `30s`、範囲 `0s`〜`5m`）は、
接続失敗、タイムアウト、HTTP 5xx、SSE内のエラー等の後に新たなLLM要求を控える期間です。
同じ接続先・モデル設定を使う機能間で共有します。待機後は1要求だけを復旧確認として通します。
待機中は `model_cooling_down` を通知し、要求やツールを自動再実行しません。
認証失敗、ツール引数エラー、ユーザーによる取消はこの待機を開始しません。
ストリームの一部を既に受信している場合は、途中から別モデルへ切り替えず失敗として扱います。

サーバーが `RingFailed` や Engram 読み出し失敗を返す場合、Reiのログだけでは原因を確定できません。
サーバー側で該当時刻の推論プロセスのログ、各rankの終了理由、ディスクI/O・空き容量・メモリを確認してください。
Reiはサーバーの再起動・設定変更を自動では行いません。
