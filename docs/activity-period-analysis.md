# Activity 週次・月次分析

`/activity weekly [today|yesterday|YYYY-MM-DD]` と `/activity monthly [today|yesterday|YYYY-MM-DD]` は保存済み Activity 標本を読み取り専用で集計する。追加撮影、LLM、分類変更、通知は行わない。

日付を含む暦週（月曜始まり）または暦月を、直前の暦週・暦月と比較する。Activity の Clock/タイムゾーンを使い、現在期間は一度固定した現在時刻まで。未来日付は拒否する。半開区間とタイムゾーンを表示し、月の日数差・夏時間を実際の経過秒に反映する。途中期間と前の全期間の量を比較している場合は明示する。

表示は観測推定分・未観測分、カテゴリ別推定時間と差、Project候補上位10、現地時刻の時間帯別・日別観測量、近接標本間のProject候補切替数。Project候補には既存の alias と confidence/filter を適用する。別モニターの候補は主活動と二重計上しない。Project未特定の標本もカテゴリ・観測量には含む。テーマは既存カテゴリを使い、新たな意味的テーマを生成しない。

標本IDの重複を除き、推定時間を期間・次の標本・現地日付境界で切り詰める。未観測は期間全体からこの推定時間を引いた値で、不活動の測定ではない。切替数は同じ continuity かつ120秒以内の近接標本で、双方に解決できる異なるProject候補がある場合のみ。中断や集中の実測ではない。

観測事実は保存標本と時刻であり、時間・主活動・Projectの帰属は推定。生産性スコアは未測定として表示する。未観測から休憩・睡眠・娯楽を推論せず、成果や生産性の増減を断定しない。自由記述・生ログ・画面タイトル・スクリーンショットは分析表示に含めない。

専用Web/Native UI、ユーザー基準による生産性スコア、意味的テーマの横断分析、集中・中断の測定、期間比較に基づくAdaptive Coachingは今後の対象。
