# 指摘の再確認

レビュー対象は `b4b0c257`。現行の実装、設定、CI を照合した。

- F-01。LLM 使用時に私設 LAN の既定 URL が使われ得る。起動直後の送信と実際の社内構成かどうかは未確認。
- F-02。固定ハッシュがなく、サイズと時間が無制限。取得は sqlite-vec を必要とする接続で発生する。manifest の同一配信元依存は TOFU と異なる。
- F-04。Phase 0 の測定時点の記録と現行の 0 件ゲートは両立する。現行の B 基準は空。
- F-05。Web の一覧と ID 照会は毎回再読込する。別インスタンスの更新が見えないのは Shell 補完と Auto Sleep が参照するスナップショット。
- F-13。Playwright の手動実行手順は client README にある。検証対象は UI フィクスチャ。
- F-15。CI の shard 照合は A の割当と A/B の重複、想定 skip を検証する。任意の B テストの欠落を保証する比較は実行していなかった。
- F-20・F-21。固定されている tempfile 3.27.0 は Unix で既定 0600。ロック不足と無制限の読み込みは確認した。既にアンロック済みの同一プロセスでは再操作でファイルを開かない。
- F-22。`behavior:` は履歴上の合成 ID。履歴の生成物照会は Run 操作用の `run_path` を通らない。
- F-23。起動時に表示する失敗と、起動後の vault 復号失敗は別経路。
- S-01〜S-03。仕様の食い違いを確認。現行の音声無効時は標準出力にフォールバックする。追補で想定された `--profile` は確認できなかった。画像の出力先は `${rei.data-dir}/images`。
- S-04・S-05。UUID 形式に合わないのは10件。feed-management の `feed` は16進数として有効。重複 ID は4仕様で使用。
- S-06〜S-18。コンポーネント名だけでは独立クラスの必須化を意味しない。temperature、facets、返信生成タイムアウトは実装済み。dry-run はログのみで、別コマンドの時間窓や空白を含むパスの扱いはそれぞれ両立する。S-08 の別接続先への再送は現行コードで確認。

PowerShell の分割検証と性能レポートの自己テストは両方成功した。この再確認でアプリ全体の起動、実通信、依存脆弱性スキャンは実施していない。
