# 設計書: Model 管理機能

## モデルの確認・切り替え

- `model` は選択中のモデルを表示し、`model <MODEL>` は `ModelHolderService` のモデル名を更新して表示する。
- Web API の `PUT /api/v1/models/current` も同じ保持先を更新する。
- モデル切り替え時は、旧モデルへの解放リクエストを送信しない。モデルのロード・解放は接続先サーバーに委ねる。
- `models` は接続先が公開するモデル一覧を表示する。

## テスト観点

- `ModelCommand` は指定したモデルを保持先に設定し、選択後のモデル名を表示する。
- 同一モデルの指定でも選択結果を表示する。
- `ModelController` はモデル一覧と現在のモデルを取得し、指定したモデルを保持先に設定する。
- Web API は不正なモデル名を拒否する。
