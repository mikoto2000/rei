# Project documentation

プロジェクトの設計・仕様ドキュメントは `.kiro` 配下で管理します。

- `specs/`: 機能単位の requirements、design、tasks
- `docs/`: 複数機能にまたがる実装リファレンスと運用資料

新しい機能仕様は `specs/<feature>/` に、横断的なAPI・観測・Tool資料は `docs/` に追加してください。

README から移した内部仕様・変更記録と既存の実装報告へのリンクは、[実装補足](docs/readme-implementation-notes.md)にまとめています。
